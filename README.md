# Итоговый проект на курсе Мобильная разработка (iOS), НИУ ВШЭ Нижний Новгород

1. При запуске необходимо ввести Bearer токен TMDB (для получения токена необходимо зарегистироваться на TMDB и перейти по ссылке https://www.themoviedb.org/settings/api)
2. Для доступа к чату с рекомендациями от ИИ необходимо ввести токен OpenRouter 
(инструкция по ссылке https://openrouter.ai/docs/api/reference/authentication)

## Основные функции приложения
1. Просмотр списка популярных фильмов
2. Просмотр карточки фильма
3. Поиск фильмов
4. Отметки и списки для избранных и просмотренных фильмов
5. Чат с рекомендациями от ИИ на основе ответов пользователя (работает на бесплатных моделях от OpenRouter, подходящую модель можно выбрать из списка)
